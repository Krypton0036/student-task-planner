# Идея проекта

Приложение для организации выполнения домашки и других задач. Можно будет задавать время выполнения, дедлайны, и распределять их по времени. Можно будет получать напоминания и смотреть уровень загруженности друзей.

# План работы

1. Сделать вход в аккаунт через firebase и настроить crashlytics & analytics
2. Сделать календарь c макетом переходов (navigation)
3. Сделать возможность добавлять и редактировать задачи (название, длительность, дедлайн, время начала)
4. Сделать, чтобы задачи сохранялись (persistence)
5. Добавить уведомления с напоминаниями (WorkManager, GCM)
6. Сделать возможность добавлять в друзья
7. Добавить уровень загруженности и сделать, чтобы друзья могли его видеть
